# 国产多模态模型选型建议

更新日期：2026-08-04。此文件仅提供选型建议，不参与程序默认配置。模型名称、价格和端点可能变化，部署前应重新核对供应商控制台。

## 推荐组合

### 通用默认：Qwen3-VL-Flash

适合论文页面、图表、截图、长文档和一般视觉理解。价格低、上下文长，适合作为文本底座的日常视觉补充。

### 文档专用：Qwen-VL-OCR

适合扫描 PDF、表格、公式、文字定位和结构化文档解析。它更像专用视觉解析器，不建议单独承担复杂实验推理；解析结果应交回底座模型综合判断。

### 疑难升级：Qwen3-VL-Plus

适合曲线图细节、空间关系、复杂视觉推理以及 Flash 结果置信度不足的页面。建议只对少量疑难页面调用。

### 备选：ERNIE 4.5 Turbo VL

当已有百度千帆账号、网络或合规要求更适合百度云时，可作为通用视觉备选。

## 建议路由

- `ocr`、`document`、`formula`：文档专用 profile 优先，通用视觉 profile 复核。
- `table`：文档专用 profile 提取结构，通用视觉 profile 检查表头、脚注和语义。
- `chart`、`vision`：通用低价 profile 优先，疑难 profile 按需升级。

这些 profile 需要用户显式配置。系统不会预设供应商、模型 ID、Base URL 或密钥变量。
